# RBF-SVM official-result archive

This directory preserves the complete official result package immediately before the fixed depth-1 PennyLane RY/CNOT fidelity kernel was promoted to primary Stage 1.

It includes the serialized RBF-SVM model, all three top-level result files, detailed official Stage 1/2/3 artifacts, and the reports/validation state that accompanied that run. These files are historical and must not be mixed with the active top-level quantum-kernel submission outputs.

Reproduction context is recorded in the archived reports and the repository configuration. The input workbook was `bank_campaign_participant_release-1.xlsx` and the archived Stage 1 model file is `stage1_final_model.joblib`.
